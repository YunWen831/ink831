# 在学校乱逛

三角色校园恐怖解谜小游戏，静态 HTML / Canvas，直接由 GitHub Pages 提供。

[开始调查](https://yunwen831.github.io/ink831/campus/) · [保留的旧版](https://yunwen831.github.io/ink831/campus/prev.html)

键盘 WASD / 方向键移动，Shift 快跑，E / Z / 空格调查，Tab / B 翻本子；手机左侧拖动移动，右侧按钮调查和切换快跑。数字谜题支持数字键、退格与回车；手机可点键盘上的「离开」。
