# 课表 App 开发约定

- 本项目的所有写入操作应位于 `D:\github\ink831\app-source\y-timetable` 内。后续命令明确使用此目录作为工作目录。
- 开发需求与排版以同目录的 `course-assistant-design.md` 为依据，不擅自扩展功能。
- 先开发安卓版本，目标测试手机为荣耀 Magic 8 Pro、Android 16。
- 首页顶部时间小、当前课程名大、下一节课稍小；当前与下一节同时显示；左上课表入口、右上设置入口；保持留白；半透明面板可开关。
- 0.2版用户反馈：学期用日历选择开学日/放假日，开学日可以不是周一，放假当天不排课；课程周次用全周/单周/双周/自定义勾选；默认时间用时间选择器；提供整周表格与每日列表。
- 首页背景覆盖系统栏，安全间距只应用于内容；日历图标保持对称居中；日期行使用等宽居中布局。
- 0.3版截图反馈：首页顶部独立全宽工具栏，图标靠左右边缘、时间日期明确居中；日期格的TextView文字也必须居中，不能仅对父容器设置gravity。长名称自适应字号/平衡换行，长备注首页仅两行预览，点开保留全文。
- 周表时间轴使用真实课程起止边界（含10:10等非整点），课程块始终优先展示完整起止时间；窄屏支持放大横向查看。统一柔和圆角按钮，取消系统默认灰块和阴影，其他页保持简洁间距。
- “各节课时间”仅作为AI导入中的可选节次换算，不在主设置中要求填写。备份默认一键保存应用内副本并可从列表恢复，文件分享/导入仅作可选操作。
- 趣味工具为骰子、自定义转盘、木鱼和用户新批准的随手涂鸦；不擅自加入其他建议中的内容。
- 0.4版用户批准：备注展开阅读区域更大；导入保留草稿、整周表格核对和原截图对照，增加清空文字及预览条目删除；避免增加找其他AI修正的往返，不增加导入变化对比/撤销。导入草稿的修改和删除不得修改已经保存的课表。
- 背景选图须能拖动、缩放、完整显示或铺满，预览保存后才应用；取消保留原背景。涂鸦支持笔色、粗细、橡皮、撤销、保存和设为背景，入口在课间工具，不增加首页拥挤度。
- 用户已要求关闭半小时进度报告，自动化已暂停。不要重新开启；完成当前授权修改后等待用户反馈。
- 0.5版用户批准前两轮六项细节修正：首页刷新保留位置、导入随作息重新换算并保留手动修改、提醒状态/补发/去重、背景可读性、保存失败保留输入、完整备份含背景与涂鸦。保持界面和功能范围，不重新加入用户否决的额外功能。新ZIP副本与旧JSON副本均可恢复，不改变AI课程导入JSON协议。
- 0.6版用户只批准小栏和设置重排，不新增内容：底部小栏可选/排序现有天气、涂鸦、骰子、转盘、木鱼，最多同时显示三项、其余横向滑动；备注在上方。备注与提醒放课表设置，天气/小栏/音效/震动放附加功能，保留界面外观。不要新增倒计时、灵感、日历、空气质量、猜拳或小游戏等讨论中的功能。
- 新下载的开发工具放在项目 `.tools` 子目录；构建缓存放在项目 `.cache` 子目录；设置项目内的 Gradle 用户目录，不使用默认用户级缓存。安装包及交付物放在项目 `output` 子目录。
- 使用进程级或项目级配置，不修改全局环境变量、系统代理、安全设置或既有 Java 安装。
- 本次用户已批准将项目迁入本仓库，并将源码及最新APK发布到 GitHub Pages。后续新增发布仍以用户授权为准。不得提交本机SDK、缓存或签名密钥。
- 首先验证构建环境和首个 APK；未验证之前不报告具体工期或声称已完成运行测试。

- 0.7版已正式命名为Y课表，手绘自适应图标。应用包名及签名保留。项目已从playground迁移，开发文件在本目录，网站发布APK在仓库software/y-timetable/downloads。用户要求清理旧版本/缓存，但必须保留更新签名及必要工具。
