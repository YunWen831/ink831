# Y课表 0.7.0 · 安卓试用版

面向安卓手机，目标测试设备：荣耀 Magic 8 Pro，Android 16。

## 安装与首次使用

1. 把 `../../software/y-timetable/downloads/Y-timetable-0.7.0.apk` 传到手机，可直接覆盖安装旧版，不先卸载。
2. 用手机文件管理器打开 APK，按系统提示允许该来源安装，再完成安装。
3. 打开“Y课表”，在日历中选择开学日和放假日，自动计算教学周。开学可以是任何星期，放假当天开始不上课。旧版学期与课表会自动兼容读取。
4. 点击首页左上课表按钮，手动添加课程时选择星期、时间和全周/单周/双周/自定义周次；或点击“粘贴课表”，复制识别指令给其他 AI，粘贴结果并检查预览。只有截图缺少时间、只写“第几节”时，才按需设置节次换算。
5. 首页右上进入设置，可选择背景、拖动调整图片位置、双指或滑块缩放、选择完整显示或铺满、调整亮度，开关半透明面板和各个附加组件。

手机只需安装 APK，不需要安装 Java、SDK 或开启 USB 调试。应用更新时使用同一签名的 APK 覆盖安装；不要先卸载，卸载会删除应用本地数据。

## 当前包含

- 小字号时钟、突出当前课程、同时展示当天下一节课；分别支持“未上课”“无课”状态。
- 随系统时间自动更新，单双周、指定周次、学期外判断。普通分钟变化只更新时钟；课程状态改变时保留首页滚动位置。
- 按教学周切换与按日查看课程，整条安排编辑、单次调课/停课/恢复、时间冲突检查。
- 点击“整周表格”查看星期为列、时间为行的整周安排；每个块上方显示上课、下课两个完整时间，左轴显示真实起止边界，不限整点。可放大查看、左右滑动；点课程打开详情，冲突课程分栏显示。
- AI JSON 文字导入、识别指令、节次换算、待核对提示、预览编辑、合并去重、明确确认替换。导入文字、预览修改和删除会暂存；提供剪贴板粘贴、清空文字、逐条删除、整周预览与原截图对照。
- 本地数据保存、一键保存本机副本、从副本列表恢复、可选分享备份和从文件恢复；新副本为包含课表/设置/背景/涂鸦/导入草稿及对照截图的ZIP，旧JSON副本仍可读取。恢复前自动保存当前内容副本，资源损坏会拒绝恢复；资源无法读取时明确提示缺失。
- 自定义背景、位置与缩放、完整显示模式、亮度、半透明面板开关和透明度。
- 课程备注两行预览，点击打开更大的阅读窗口；可选上课提醒。首页底部为可自定义的小栏，包含现有天气、涂鸦、骰子、转盘、木鱼，最多同时显示三项，其余左右滑动，备注保留在小栏上方。
- 随手涂鸦（五种笔色、粗细、橡皮、撤销、清空、自动暂存、导出PNG和设为背景），多骰子、自定义等概率转盘、木鱼，以及声音和震动开关。

首次启动不会自动加入示例课程，示例在 `sample-course-table.json` 中，可复制后导入。晚间或没有课程时显示“未上课 / 无课”是正常行为。

## 新功能用法

- 小栏与设置：进入“设置 → 附加功能 → 小栏内容与顺序”，勾选内容，用上下箭头排序，保存后应用。“显示底部小栏”可整体关闭，关闭不会丢失选择。天气显示简短天气/温度，点击查看城市、缓存更新时间及刷新入口。所有内容取消勾选后不显示空栏。
- 设置分类：“课表设置”包含学期、备份、备注开关、上课提醒及其提前时间/状态；“界面外观”保留背景和面板；“附加功能”包含小栏、天气城市、全部现有工具、音效和震动。旧版天气/工具开关在升级时迁移，课表及提醒设置保留。没有增加新小游戏或其他日常功能。

- 备注：点击首页的备注文字，在占屏幕大部分区域的窗口中阅读、滚动和选择文字。
- 导入：关闭导入页面或切换其他软件后，再打开“粘贴课表”可继续；原文字未改动时，预览里已修改或删除的条目会保留。改变粘贴文字后重新校验。补充节次作息后重新换算待核对条目；本版记录按节次换算的预览来源，作息改变时更新时间，保留课程名称、地点、周次和备注的修改。手动修改预览课程时间后，停止自动覆盖该条目的时间。成功导入后清空本次草稿。
- 核对：导入预览中切换“条目列表/整周表格”，可切换教学周。表格只包含本次可导入条目，待核对内容在列表中补充。点击表格课程也能修改或删除。“对照截图”可选择原图，打开后支持放大、拖动；不上传图片、不自动识图。
- 删除：清空粘贴内容和删除预览条目均不修改已经保存的课表。保留原有合并去重和明确确认替换方式，没有新增AI往返修正流程、变化对比或导入撤销。
- 背景：选图后先调整、保存再应用；取消保留原背景。“调整背景位置”可随时重新调整。关闭完整显示模式时铺满画面；开启时显示整张原图，留空位置使用浅色填充。支持照片方向信息。自定义图片按文字区域的亮暗自动添加柔和浅色渐变，默认山景保持原样；不改变半透明面板开关。
- 涂鸦：进入“课间工具 → 随手涂鸦”。当前画布自动保存到软件内，下次继续；“保存图片”选择手机上的保存位置；“设为背景”进入位置与缩放预览，保存后才应用。已经导出的图片和应用中的背景不会被清空画布删除。

新备份会将背景和对照截图复制进文件包，并包含涂鸦与导入草稿，恢复时使用新的本机图片关联，不依赖原手机的图片路径。被删除或无法读取的图片、损坏的草稿会在副本中明确标注未包含，不能凭空恢复。旧JSON副本只恢复原有课表/设置，不会覆盖画布或导入草稿。卸载会删除本机内容，长期保存请分享备份或导出PNG。

保存未成功时会提示并回退课表/设置，课程编辑、导入预览和背景调整窗口保留供重试。恢复文件会先校验内容，图片与画布先暂存；画布的原文件在课表提交成功前保留，出错尝试回退，并保留恢复前副本供重新恢复。严重存储故障下若回退也失败，需要腾出空间后从副本恢复，不能承诺所有硬件故障下自动恢复成功。

## 提醒与天气

上课提醒初始关闭。启用后按提示允许通知；需要准时提醒时，还应允许系统的“闹钟和提醒”权限。未获得准时提醒权限时采用系统的非精确提醒，可能延后。系统强制停止应用可能影响提醒；荣耀系统的实际后台行为须在手机上验证。

开启提醒时，如果已经错过提前提醒时间，但课程尚未开始，会补发一次；已经开始的课程不补发。已发送安排会记录以避免重复；系统延迟的既有提醒只在课程尚未结束时发送。同一开始时刻的课程合并通知。设置中的提醒状态会显示通知开关、课程通知通道、下一次安排或失败信息，点击可检查权限并重试。系统通知发送及闹钟行为仍须真机核验。

天气初始关闭。开启后手动搜索并选择城市，不索取定位。天气来自 Open-Meteo，显示缓存更新时间；无法联网时保留旧数据或明确显示不可用，不生成虚假天气。

天气来源与使用说明：https://open-meteo.com/ 。

## 源代码与本机构建

全部文件位于本项目目录内。`app/src/main` 为应用源代码与资源，`tests` 为规则测试，`.tools` 为 SDK 和本地测试签名，`.cache` 为构建缓存，`output` 为交付物。

本项目使用 Java 和 Android 官方 SDK 工具直接构建，不依赖运行时第三方库，暂不要求 Android Studio 或 Gradle。Java 25 与当前工具组合已成功完成构建。

已有SDK时，在项目目录执行：

```powershell
.\build.ps1 -TestOnly
.\test-import.ps1
.\build.ps1
```

`test-import.ps1` 的 JSON 测试运行库仅在 `.tools/downloads/json-tests.jar`，不打入 App。重建环境时可从 Maven Central 下载 org.json:json:20250517 至该路径。

新电脑需要先安装可用 JDK，再运行 `setup.ps1` 下载项目内 SDK；执行 setup 表示接受所下载 Android SDK 的许可。构建过程只设置当前进程的路径和临时目录，不改全局环境配置。

APK 目前使用本地测试签名，签名文件保存在 `.tools/signing/local-test.jks`；GitHub源码不包含 SDK、缓存或签名文件。保留此签名文件可继续为当前安装版本生成覆盖更新包，正式上架应另外准备发布签名。
